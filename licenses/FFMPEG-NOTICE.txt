FFMPEG IN ARROW SWITCH
======================

Arrow Switch runs a separate, unmodified ffmpeg program (bin/ffmpeg) to read audio.
Arrow Switch's own code talks to it only by starting it as a process and reading its
output; ffmpeg is not linked into Arrow Switch.

Program:       FFmpeg 9.0.1, static macOS build (universal arm64 + x86_64)
Built by:      Martin Riedl, https://ffmpeg.martin-riedl.de
Copyright:     (c) 2000-2026 the FFmpeg developers and the authors of the libraries below
License:       GNU General Public License, version 3 (see GPL-3.0.txt). This build is
               configured with --enable-gpl --enable-version3, so the combined binary is
               distributed under GPLv3.

Configuration:
  --pkg-config-flags=--static --enable-gray --enable-libxml2 --enable-version3
  --enable-gpl --enable-openssl --enable-libfreetype --enable-fontconfig
  --enable-libharfbuzz --enable-libbluray --enable-libsnappy --enable-libsrt
  --enable-libvmaf --enable-libass --enable-libklvanc --enable-libzimg
  --enable-libzvbi --enable-libaom --enable-libdav1d --enable-libopenh264
  --enable-libopenjpeg --enable-librav1e --enable-libsvtav1 --enable-libvpx
  --enable-libvvenc --enable-libwebp --enable-libx264 --enable-libx265
  --enable-libmp3lame --enable-libopus --enable-libvorbis --enable-libtheora

SOURCE CODE
-----------
The corresponding source is available free of charge, attached to every Arrow Switch
release at https://github.com/erinuckuzular-ai/arrow-switch/releases :

  ffmpeg-9.0.1.tar.xz              FFmpeg 9.0.1 source
  ffmpeg-build-script.tar.gz       the build scripts used to produce this binary; they
                                   name and fetch the exact source of every library above

Upstream copies: https://ffmpeg.org/releases/ffmpeg-9.0.1.tar.xz and
https://git.martin-riedl.de/ffmpeg/build-script

You may replace bin/ffmpeg with your own build of ffmpeg; Arrow Switch will use it.
