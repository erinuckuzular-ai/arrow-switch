Arrow Switch

Automatic multicam podcast editing for Adobe Premiere Pro.

Before you start

  • Quit Premiere Pro. It only picks up new panels when it starts.
  • You need Premiere Pro 2022 or newer.

What this installs

  • The Arrow Switch panel, under Window → Extensions.
  • A bundled audio decoder, so there is nothing else to set up.

Your projects are never altered: every cut lands on a new sequence.
